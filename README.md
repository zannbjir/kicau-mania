# 🐾 Hand Tracking: Kicau Mania

Proyek Python sederhana untuk mendeteksi gestur tangan menggunakan webcam.  
Jika kamu melakukan **pose "tutup mulut"**, program akan otomatis membuka video kucing kicau mania di tab baru 🐱

---

## 🛠 Requirements

Pastikan kamu sudah menyiapkan:

- **Python 3.11** *(disarankan untuk menghindari error kompatibilitas)*
- **Webcam / Kamera**
- File berikut di dalam folder project:
  - `hand_landmarker.task` → model AI
  - `kicau.mp4` → video kucing

---

## 📦 Instalasi

Jalankan perintah berikut di terminal / CMD:

```bash
python -m pip install opencv-python mediapipe numpy
```

## 📦 Jalan

Jalankan perintah berikut di terminal / CMD:

```bash
python main.py
```
Atau
```bash
py main.py
```
